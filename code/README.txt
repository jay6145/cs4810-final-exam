How to run project:

1. Download project directory and load it into VS code
2. Navigate to the index.html inside the subfolder named "code"
3. Click the settings gear icon and click command palette, then open
with live server.
4. Your browser should then render the scene
5. On the left, there is a sidebar that allows us to change the scene.
To change the scene, utilize the sliders and toggles to do things such
as changing the speed of the day/night cycle, what time of the day it is,
enabling ambient occlusion, shadow mapping quality, dynamic weather effects,
and toggling certain wildlife on and off.
6. At the bottom of the sidebar, there is a toggle to enable auto camera.
Click it to allow the camera to pan around the scene, and use the slider
to control how fast it does this.
7. You can zoom in and out of the scene using the trackpad's gestures.
